# Icons

PNG conversions of the bitmaps and icons of the original FictionBook Editor
2.7 (`FBE/res/`). Everything in this
directory is generated by `tools/resources-import/import_icons.py` (ImageMagick 7)
from the reference checkout; do not edit the PNGs by hand.

Conversion rules:

* Whole strips are written to `strips/` with magenta (`#FF00FF`) made
  transparent (`-transparent magenta`). The 32-bit strips already carry an
  alpha channel (their magenta pixels have alpha 0), so the key only matters
  for the legacy 24-bit `toolimg.bmp`.
* Toolbar strips are split into square cells. Cell *i* of a strip is the image
  of the *i*-th `BUTTON` of the matching `TOOLBAR` statement in `FBE/FBE.rc`;
  `SEPARATOR` lines do not consume a cell. Files are named after the command
  id in lower case (`ID_FILE_NEW` -> `id_file_new.png`). Cells beyond the last
  `BUTTON` are kept as `unused-cell-NN.png`.
* All PNGs are 8-bit RGBA (`PNG32`), without timestamp chunks.

## Document tree image list (`tree16/struct-NN.png`)

`struct.bmp` is loaded with `CreateFromImage(IDB_STRUCTURE, 16, 32,
RGB(255,0,255))`. Indices are assigned in `ElementDescMnr.cpp` /
`TreeView.cpp`: 0 = body and section, 3 = image and poem (`IMG_ID_*`
constants); the old inline code also used 6 for subtitles; the built-in element
descriptors (`ElementDescMnr.cpp:231-235`) use 21 = image, 12 = annotation,
15 = history and 3 = poem / stanza. The images come in
groups of three: base image N, N+1 = "drop as sibling" and N+2 = "drop as
child" variants shown while dragging tree nodes (`TreeView.cpp`,
`SetItemImage(..., m_drop_item_nimage + 1/2)`). Other indices are used by
scripted element descriptors (`files/TreeCmd`), which add their own icons at
run time. Visual content by group: 00-02 page (section/body), 03-05 picture
(image), 06-08 ornament (poem), 09-11 wide bar, 12-14 triangle, 15-17 circle,
18-20 bar, 21-23 letter "A", 24-26 framed box (cite/table), 27-29 ornament,
30-32 filled square.

## Regeneration

    python3 resources/tools/import_icons.py \
        --ref /path/to/fictionbookeditor/FBE --out resources/icons
