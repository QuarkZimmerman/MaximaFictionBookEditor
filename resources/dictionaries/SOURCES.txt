Hunspell spelling dictionaries - provenance
===========================================

Three dictionaries: en_US and ru_RU from the LibreOffice dictionaries
repository (this section), uk_UA from the dict_uk project (second section).

en_US, ru_RU - LibreOffice dictionaries
=======================================

Both dictionaries were downloaded unmodified (byte-exact, LF line endings,
no BOM) from the LibreOffice dictionaries repository:

Hunspell reads the .dic file in the encoding declared by the .aff "SET" line,
so the files must stay byte-exact; do not re-encode or normalise them.

Versions
--------
  en_US : SCOWL-derived "en_US Hunspell Dictionary" version 2020.12.07
          (http://wordlist.sourceforge.net, see en_US.txt); the .aff carries
          LibreOffice fixes up to 2024-01-29 (Marco A.G. Pinto).
  ru_RU : Russian dictionary (BSD-style licence, see ru_RU.txt),
          with the 2012-08-24 TRY-line fix by Laszlo Nemeth (see ru_RU.txt).

Regeneration
------------
  SHA=67032ee957631908098a72edf48dc81cac27e369
  BASE=https://raw.githubusercontent.com/LibreOffice/dictionaries/$SHA
  curl -fL -o en_US.aff $BASE/en/en_US.aff
  curl -fL -o en_US.dic $BASE/en/en_US.dic
  curl -fL -o en_US.txt $BASE/en/README_en_US.txt
  curl -fL -o ru_RU.aff $BASE/ru_RU/ru_RU.aff
  curl -fL -o ru_RU.dic $BASE/ru_RU/ru_RU.dic
  curl -fL -o ru_RU.txt $BASE/ru_RU/README_ru_RU.txt
  sha256sum -c   # against the table above
To update to a newer upstream state, take the new SHA from
https://api.github.com/repos/LibreOffice/dictionaries/commits/master and
refresh the table above.

uk_UA - dict_uk (ВЕСУМ / VESUM)
===============================

The Ukrainian dictionary is the Hunspell distribution of the dict_uk project,
taken unmodified (byte-exact, LF line endings, no BOM) from the release
archive of a tagged GitHub release:

  Project    : https://github.com/brown-uk/dict_uk

    Aggregated data (constitution 2.3.0, principle VI; decision D16 of feature

    its word data are CC BY-NC-SA 4.0 and its tooling GPL-3.0; only the
    Hunspell derivative (distr/hunspell) carries the MPL 1.1 terms used here.

Regeneration
------------
  TAG=v6.8.6
  curl -fL -o hunspell-uk_UA_${TAG#v}.zip \
    https://github.com/brown-uk/dict_uk/releases/download/$TAG/hunspell-uk_UA_${TAG#v}.zip
  echo "043ae50d3a30beda0d4aa67562fdbee576e2f862eb6120357c1e5ae5ed3d5e9e  hunspell-uk_UA_${TAG#v}.zip" | sha256sum -c
  unzip -o hunspell-uk_UA_${TAG#v}.zip uk_UA.aff uk_UA.dic
  sha256sum -c   # against the table above
To update, take the newest tag from https://github.com/brown-uk/dict_uk/releases,
refresh the archive checksum, the table and uk_UA.txt (re-read the three
notice URLs above at the new tag; the copyright years and the licence wording
may change), and run python3 tools/licence-check.py.
