# Your data folder / Ваша папка данных / Ваша тека даних

## English

This is the editor's folder for your own additions:

- `blank.fb2` - your template of new documents, used by *File > New* as written; without it the
  bundled template is used (*Settings > Other* shows the template in effect);
- `genres/` - your own genre lists (see `genres/readme.md`);
- `scripts/` - your own scripts (see `scripts/readme.md`);
- `dictionaries/` - your own spelling dictionaries (see `dictionaries/readme.md`).

The other files here belong to the editor (for example your custom dictionary `custom.dic`); leave
them to it. *Settings > Other* lists the files of these folders that the editor does not use, with
the reason.

## Русский

Это папка редактора для ваших собственных дополнений:

- `blank.fb2` - ваш шаблон новых документов, «Файл > Создать» использует его как есть; без него
  используется встроенный шаблон («Настройки > Другое» показывает действующий шаблон);
- `genres/` - ваши списки жанров (см. `genres/readme.md`);
- `scripts/` - ваши скрипты (см. `scripts/readme.md`);
- `dictionaries/` - ваши словари проверки орфографии (см. `dictionaries/readme.md`).

Остальные файлы здесь принадлежат редактору (например, ваш словарь `custom.dic`); оставьте их ему.
«Настройки > Другое» перечисляет файлы этих папок, которые редактор не использует, с причиной.

## Українська

Це тека редактора для ваших власних доповнень:

- `blank.fb2` - ваш шаблон нових документів, «Файл > Створити» використовує його як є; без нього
  використовується вбудований шаблон («Налаштування > Інше» показує чинний шаблон);
- `genres/` - ваші списки жанрів (див. `genres/readme.md`);
- `scripts/` - ваші скрипти (див. `scripts/readme.md`);
- `dictionaries/` - ваші словники перевірки правопису (див. `dictionaries/readme.md`).

Інші файли тут належать редакторові (наприклад, ваш словник `custom.dic`); залиште їх йому.
«Налаштування > Інше» перелічує файли цих тек, які редактор не використовує, з причиною.
