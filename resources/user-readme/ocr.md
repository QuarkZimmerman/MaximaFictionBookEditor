# Your own OCR language packs / Ваши языковые пакеты OCR / Ваші мовні пакети OCR

## English

Put Tesseract OCR language files (`<code >.traineddata`, such as `ces.traineddata`, `jpn.traineddata`,
or `heb.traineddata`) here to add new languages for PDF OCR import.

You can also place a higher-accuracy (`tessdata_best`) file with the same name as a bundled language
(for example `rus.traineddata` or `eng.traineddata`) here: a file in this folder (or in your custom
OCR folder in *Settings > OCR*) overrides the bundled fast model without modifying the program folder.

Download additional or higher-accuracy language packs from the official Tesseract repositories:
- Overview and guide: <https://tesseract-ocr.github.io/tessdoc/Data-Files.html>
- Higher accuracy (`tessdata_best`): <https://github.com/tesseract-ocr/tessdata_best>
- Fast compact packs (`tessdata_fast`): <https://github.com/tesseract-ocr/tessdata_fast>

Press *Apply* in *Settings > OCR* to pick up new or replaced files immediately without restarting.

## Русский

Поместите сюда языковые файлы Tesseract OCR (`<код>.traineddata`, например `ces.traineddata`,
`jpn.traineddata` или `heb.traineddata`), чтобы добавить новые языки для распознавания PDF (OCR).

Вы также можете положить сюда файл повышенной точности (`tessdata_best`) с тем же именем, что и у
встроенного языка (например, `rus.traineddata` или `eng.traineddata`): файл из этой папки (или из
выбранной вами пользовательской папки OCR в «Настройки > OCR») автоматически заменит встроенную
быструю модель, не изменяя папку программы.

Скачать дополнительные или более точные языковые пакеты можно из официальных репозиториев Tesseract:
- Обзор и описание: <https://tesseract-ocr.github.io/tessdoc/Data-Files.html>
- Повышенная точность (`tessdata_best`): <https://github.com/tesseract-ocr/tessdata_best>
- Быстрые компактные пакеты (`tessdata_fast`): <https://github.com/tesseract-ocr/tessdata_fast>

Нажмите «Применить» в «Настройки > OCR», чтобы новые или обновлённые файлы подхватились сразу без
перезапуска.

## Українська

Помістіть сюди мовні файли Tesseract OCR (`<код>.traineddata`, наприклад `ces.traineddata`,
`jpn.traineddata` або `heb.traineddata`), щоб додати нові мови для розпізнавання PDF (OCR).

Ви також можете покласти сюди файл підвищеної точності (`tessdata_best`) з тією самою назвою, що й
у вбудованої мови (наприклад, `ukr.traineddata` або `eng.traineddata`): файл із цієї теки (або з
вибраної вами власної теки OCR у «Налаштування > OCR») автоматично замінить вбудовану швидку модель,
не змінюючи теку програми.

Завантажити додаткові або точніші мовні пакети можна з офіційних репозиторіїв Tesseract:
- Огляд і довідка: <https://tesseract-ocr.github.io/tessdoc/Data-Files.html>
- Підвищена точність (`tessdata_best`): <https://github.com/tesseract-ocr/tessdata_best>
- Швидкі компактні пакети (`tessdata_fast`): <https://github.com/tesseract-ocr/tessdata_fast>

Натисніть «Застосувати» в «Налаштування > OCR», щоб нові або оновлені файли запрацювали одразу без
перезапуску.
