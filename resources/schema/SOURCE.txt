Notes
-----
* FictionBook.xsd imports FictionBookGenres.xsd, FictionBookLang.xsd and
  FictionBookLinks.xsd by relative schemaLocation; FictionNotes.xsd imports
  FictionBook.xsd. Keep the five files together in one directory.
* FictionBookGenres.xsd enumerates 186 genre codes (xs:enumeration). The
  bundled copy in the original FictionBook Editor (FBE/FictionBookGenres.xsd)
  is an older, shorter list (128 codes); the upstream fb2 repository copy is
  used here.
* FictionNotes.xsd upstream uses CRLF line endings; it is kept byte-exact
  (all other files use LF).
